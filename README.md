## Requisitos
- Python 3.10 ou superior

## Instalação
```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Verificação inicial
```bash
pytest
python -m surveyor --help
```
